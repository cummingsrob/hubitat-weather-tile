# hubitat-weather-tile

A planned standalone Hubitat Elevation app that shows a multi-day weather forecast strip on Hubitat dashboards. It is modelled on the forecast strip in [Rachio-Community](https://github.com/lnjustin/Rachio-Community), but without any irrigation dependency, and with a choice of weather sources and display options. The app would serve the forecast as an SVG image from its own web endpoint, which avoids the ~1,024-character limit on dashboard tile attributes.

**Status:** requirements draft. No code yet. See [REQUIREMENTS.md](REQUIREMENTS.md).
